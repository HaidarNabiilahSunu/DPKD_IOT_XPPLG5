## 🔌 About The Project

**DPKD_IOT_XPPLG5** adalah repositori penyimpanan tugas dan proyek praktikum **Internet of Things (IoT)** yang dikembangkan oleh **Haidar Nabiilah Sunu** (Kelas X PPLG 5) dalam rangka memenuhi tugas mata pelajaran **Dasar-Dasar Program Keahlian (DPKD)** jurusan Pengembangan Perangkat Lunak dan Gim.

Proyek ini mencakup eksplorasi pemrograman mikrokontroler, pembacaan data sensor, kontrol perangkat fisik (aktuator), serta pengiriman data IoT ke platform cloud/dashboard secara *real-time*.

### ✨ Fitur & Topik Pembelajaran
* **Pemrograman Mikrokontroler:** Penulisan logika program menggunakan C/C++ (Arduino IDE) atau MicroPython untuk mengontrol modul mikrokontroler.
* **Integrasi Sensor & Aktuator:** Pemrosesan input dari berbagai sensor (suhu, kelembapan, jarak, PIR, dll.) dan kontrol output (LED, Relay, Buzzer, Motor).
* **Konektivitas & Komunikasi IoT:** Pengiriman data melalui protokol Wi-Fi/HTTP/MQTT ke platform IoT (seperti Blynk, Thingspeak, atau Wokwi).
* **Simulasi & Rangkaian:** Perancangan skematik rangkaian fisik maupun simulasi interaktif.

### 🛠️ Teknologi & Tooling
* **Hardware:** ESP32 / ESP8266 / Arduino & Modul Sensor/Aktuator
* **Software:** Arduino IDE / VS Code / Wokwi Simulator
* **Bahasa Pemrograman:** Embedded C / C++ / MicroPython
